# SKAI

> A personal Large Language Model (LLM) built from scratch to understand how modern AI models work under the hood.

## 🚀 Project Timeline

- **Started:** 29 July 2026
- **Phase 1 Completed:** 30 July 2026

---

## 📌 Phase 1

The first phase focused on building the fundamental components required for an LLM.

### ✅ Completed

- Text input pipeline
- Vocabulary creation
- Token encoder
- Token decoder
- Context window generation
- Target window generation
- Batch creation for training

---

## 🎯 Goal

The goal of this project is to build a complete Large Language Model from scratch while understanding every component involved, rather than relying on existing frameworks or pretrained models.

More updates will be added as the project progresses.
